# 01 - Quality Data Analysis Tool

## What it does
A simple tool to analyse manufacturing inspection data.

- Input dimension values, target, and tolerance
- Highlights out-of-spec values
- Shows mean, min, max
- Defect count analysis with bar chart

## How to run
pip install -r requirements.txt
streamlit run quality_tool.py
